Login Flow Diagram

Alur login untuk 3 role berbeda: User, Staff, dan Admin

USER Customer Role

  • Login: POST /masuk → verify credentials → create session → redirect /profil
  • Akses: /reservasi-saya, /keranjang, /reservasi/buat, batal booking
  • Tidak bisa: /staff/* dan /admin/*
  • Middleware: role:user

STAFF Staff Role

  • Login: POST /masuk → verify credentials → create session → redirect /profil
  • Akses: /staff/sewa, /staff/stok, /staff/artikel, /staff/dashboard
  • Tidak bisa: /admin/* (user management, assessment)
  • Middleware: role:staff,admin

ADMIN Admin Role

  • Login: POST /masuk → verify credentials → create session → redirect /profil
  • Akses: Semua /staff/* + /admin/* (full access)
  • Staff Panel: inventory, rentals, articles, analytics
  • Admin Panel: user management, staff assessment, audit logs
  • Middleware: role:admin
